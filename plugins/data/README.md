# data 1.0.0

Data pipelines, database operations and reproducible machine-learning lifecycle workflows with explicit correctness and recovery contracts.

Install declared dependencies. Load only relevant skills/resources; required availability is not a recursive workflow.

| Skill | Purpose |
|---|---|
| [data-pipeline](skills/data-pipeline/SKILL.md) | Build or change batch/stream data pipelines and data contracts. Use for ingestion, transformation, backfills, lineage and data-quality failures. |
| [database-operations](skills/database-operations/SKILL.md) | Operate and optimize persistent databases safely. Use for query tuning, isolation/locking, replication, backups, restore drills or database incidents. |
| [ml-lifecycle](skills/ml-lifecycle/SKILL.md) | Build or revise reproducible model training and serving pipelines. Use for dataset splits, experiments, model evaluation, deployment or drift; not for every LLM API integration. |
