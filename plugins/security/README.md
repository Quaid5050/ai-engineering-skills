# security 1.0.0

Threat modeling, identity and supply-chain verification with explicit assets, trust boundaries and testable controls.

Install declared dependencies. Load only relevant skills/resources; required availability is not a recursive workflow.

| Skill | Purpose |
|---|---|
| [identity-access](skills/identity-access/SKILL.md) | Implement or review authentication, sessions and authorization. Use for sign-in, account recovery, service identity, tenant permissions or token lifecycle changes. |
| [supply-chain](skills/supply-chain/SKILL.md) | Secure dependency, build and artifact delivery paths. Use for package updates, CI permissions, release provenance, secrets or dependency compromise review. |
| [threat-model](skills/threat-model/SKILL.md) | Produce or update an actionable threat model. Use for changed trust boundaries, sensitive data, privileged capabilities or explicit abuse/security review. |
